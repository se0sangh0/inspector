## 규격과 검증

PNG는 1254×1254 생성 원본을 그대로 보존한다.
Unity 표준 임포트에서 64×64, Sprite/Single, Point, 무압축, 밉맵 없음으로 설정했다.
리소스 경로는 `RemakeV1/SystemIcons/icon_…`이며 원본과 `.meta`를 저장소에 보관한다.
8개 모두 임포트 후 실제 텍스처의 바깥 8픽셀 알파값이 0인 것을 확인했다.
따라서 생성 원본에 남은 미세한 부분 알파와 게임에 로드되는 텍스처 검사를 구분한다.
이미지 파일을 별도 코드로 다시 그리거나 알파를 임의로 덮어쓰지 않았다.

아이콘 에셋 검사 8개, 실제 GamePlayScene UI 계약 검사 71개를 통과했다.
재화 수량 라벨, 기존 버튼 동작과 배경, 한국어·영어 라벨, 재열기, 누락 리소스 폴백을 확인했다.
실제 TTS46 UI2 빌드에서 재화·수첩·설정·로그의 아이콘과 클릭·닫기, 한국어/영어 설정을 확인했다. 닫기 중복을 수정한 [후속 검증 기록](../../../../../docs/handoff/아이콘_실제화면_검증_및_TTS46_2026-09-28.md)을 확인한다.

## 생성 방식과 요청

이번 두 수정본은 내장 image_gen의 편집으로 생성했다. 별도 API 키나 이미지 API를 사용하지 않았다.
영혼석은 기존 실루엣을 보존하며 큰 픽셀 덩어리와 두 청록 균열을 강조하도록 요청했다.
설정은 세 막대와 세 손잡이만 보존하며 균열·미세 질감을 제거하고 두께를 늘리도록 요청했다.
정확한 두 프롬프트는 `manifest.json`의 `newVariants[].prompt`에 있고, 전날 6종 프롬프트는 `imports[].prompt`에 있다.
기존 원본, 새 생성 원본, Unity 소비본의 해시와 경로를 함께 기록했다.
