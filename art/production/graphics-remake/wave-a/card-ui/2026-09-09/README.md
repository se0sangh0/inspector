## 제작 기준

- 카드 배경에는 역할 상징·문자·숫자를 넣지 않았습니다. 배지와 텍스트는 UI에서 별도로 올립니다.
- 공격·방어·지원의 기존 빨강·파랑·초록 구분을 낮은 채도의 가죽색으로 옮겼습니다.
- 배지 상징은 현재 구현의 검·방패·하트를 유지했습니다.
- 현재 카드 표시 크기는 172.5×280입니다. 비교 페이지는 이 크기의 예시이며 실제 게임 실행 결과가 아닙니다.

## Unity 적용 · 2026-09-16

- 원본 PNG 6장을 `Assets/Resources/RemakeV1/CardUI/`에 그대로 복사했습니다.
- 카드에는 새 역할 배경과 심볼을 연결했습니다. 숫자는 밝은 상아색입니다.
- 스택 표시에도 같은 심볼을 연결했습니다.
- 배지는 정사각 Sprite 영역을 사용합니다. 긴 변의 75%를 그림이 차지합니다.
- 배경 최대 1024px, 배지 최대 256px로 임포트합니다. Point 필터를 사용합니다.
- 기존 카드 비율을 유지하며, 배경은 Simple 방식으로 표시합니다.
- Unity 컴파일과 두 해상도의 Preview Scene 검증을 통과했습니다.
