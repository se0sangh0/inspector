## 먼저 볼 결과

- 그래픽 재제작 폴더의 **29개 파일은 원격 main과 내용이 일치**합니다. PNG 19장(배경 1·앵커 6·동작 시트 12), 문서 9개, SVG 미리보기 1개입니다.

- 기존 파일의 GUID·애니메이션 연결을 유지해야 하므로 파일을 바로 덮어쓰지 않습니다. 후보의 최종 목적지는 아래 제안 경로이며 현재 존재하는 연결이 아닙니다.

## 연결에서 먼저 해결할 점

1. 캐릭터는 PNG만으로 교체되지 않습니다. Animator의 클립 Sprite 참조·상태/트리거·초상화 Idle 첫 프레임·flipSprite·visualScale을 함께 검증합니다.
2. 적 JSON 4종의 정적 spritePath가 없는 Characters/test_enemy_goblin을 가리킵니다. 현재 Animator 표시와 별개로 누락된 fallback을 정리해야 합니다.
3. GameStartScene/GamePlayScene의 일부 Background가 소스 없는 GUID를 참조합니다. StartBgImage와 BattleBackground의 실제 표시 경로를 분리해 검증합니다.
4. 단서의 현재 로더는 ResultImage 경로입니다. 새 Clues 경로와 9종 안정 ID 배정을 연결하고, 동일 단서의 발견 자막·상세는 원본 1장을 공유합니다.
5. 이벤트 모델에는 삽화 필드가 없고 선택지마다 회색 더미가 있습니다. EVT-01 공용 상단 삽화 1장 구조로 연결해야 합니다.
6. 현재 전투 배경은 일반·엘리트가 같은 Battle_Normal을 사용합니다. 4층 협곡·교회 등 별도 장소의 표시 경로가 필요합니다.
7. 런타임 적 배치는 과거 6노드 구현 흔적이 남아 있습니다. 기획의 2층·3층 정비·EVT·4층·5층·6층 흐름을 아트 교체 완료의 실플레이 검수에 사용합니다.

## 검증과 보존

- 생산 원본의 경로·크기·색 모드·해시·원격 추적 여부는 JSON 목록에 기록했습니다.
- 서로 다른 콘텐츠에 같은 이미지를 잘못 배정하지 않도록 assetId·파일 경로·SHA-256을 비교합니다. 같은 단서의 자막/상세 공유, 같은 EVT-01의 선택지 공용 삽화는 정상입니다.
- 승인 전 기존 파일 삭제·덮어쓰기·GUID 재사용을 하지 않습니다. 런타임 최종 파일은 RemakeV1 아래 용도별 폴더로 연결합니다.
- 반려본 8장과 작업용 QA 자료는 _workspace에 보존하고 푸시 대상에서 제외합니다. 인쇄 파생본·개인 행정 자료·폰트 파일도 공개 커밋에 추가하지 않습니다.
- Unity Editor가 이 Mac에 없어 컴파일·슬라이스·플레이 검증을 수행하지 못했습니다. 정적 파일/참조 확인과 승인을 게임 실행 검증으로 표현하지 않습니다.
