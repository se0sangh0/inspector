## 이번 제작 범위

- 2층 핵심 단서: 찢어진 바구니, 돌을 둘러놓은 비탈, 나뭇가지로 덮은 바위 틈
- 3층 경로: 수레가 선 길, 흰 천 표식, 갈라진 비탈
- 3층 핵심 단서: 밧줄에 매단 뿔, 길목의 낮은 장벽, 숲을 향한 목책
- 4층 협곡 전투 배경: 캐릭터·UI 없는 공용 환경

단서·경로 9장은 각각 1024×1536 RGB, 배경은 1672×941 RGB PNG입니다. 열 개의 내용 해시는 서로 다릅니다.

## 적용한 기준

최신 [16-E 기획 원문](https://app.notion.com/p/3c06aef5baac8133a093dd0f57a043d4)과 [16-G 그래픽 기준](https://app.notion.com/p/3cc6aef5baac81a5a228f2d8562cf292)을 따랐습니다.

- 경로 그림에는 선택 전 환경과 징조만 담고, 대응하는 핵심 단서는 별도 이미지로 제작했습니다.
- 3층 수레와 사람의 시선은 해당 원문에 있는 소재입니다. 이전 2층 이미지의 인물·수레 제외를 전 구간 금지로 확대하지 않았습니다. 인물은 정체를 특정하지 않는 원경 실루엣으로 제한했습니다.
- 3층 경로에 교회 간판·모집 화면·보상이나 발견 후 단서를 그리지 않았습니다.
- 단서는 일상 물건과 배치 중심으로 그렸으며 숨겨진 진실을 직접 설명하는 인물·문양·문장을 넣지 않았습니다.
- 4층 배경에는 개별 경로의 수레나 단서, 캐릭터를 합치지 않았습니다.
- 이미지 안에 문자·숫자·UI를 넣지 않았습니다. 검토 화면의 문구·크롭·참고선은 HTML 표시입니다.
- 생성 원본을 보존하며, 같은 단서의 발견 자막과 상세 화면은 한 원본을 공유합니다.

## 검증과 남은 작업

파일 규격·RGB 형식·내용 해시와 경로/단서 짝을 확인했습니다. 시각 검토 결과는 manifest의 visual_review에 기록합니다.

실제 자막과 크롭, 장벽의 바깥/안쪽 및 목책 방향의 전달, 캐릭터를 올린 전투 배경 밝기는 Unity에서 추가 검증해야 합니다. 원본 생성이 임포트·연결·플레이 검증 완료를 뜻하지 않습니다.

이전 검토본 10종은 그대로 유지합니다. 이번 생성본까지 신규 검토 후보는 20종이며, 이 수치는 전체 제작 마스터의 승인 완료 수가 아닙니다. 기존 Unity 에셋·GUID·기획·Notion 승인 상태·Git 원격은 변경하지 않았습니다.
