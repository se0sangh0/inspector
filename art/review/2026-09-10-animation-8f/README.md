## 결과 규격

- 대상: 원소술사·봉쇄병·척살자·치유사·고블린·약탈자의 대기와 기본 동작

- 프레임 순서: 윗줄 왼쪽부터1~4, 아랫줄 왼쪽부터5~8
- 개별 프레임: 애니메이션별01.png~08.png, 모두384×512 RGBA
- 출력 위치: `art/production/graphics-remake/wave-a/animation-8f/2026-09-10/normalized_v1/`
- 원본 위치: 같은 날짜 폴더의 `raw/`. 격자무늬가 그려진 RGB 원본이므로 게임에는 보정본을 사용합니다.

## 보정 방법

1. 원본의 중립색 격자와 외곽 연결 영역을 분리했습니다. 회색 금속·옷감은 단순 밝기 삭제로 처리하지 않았습니다.
2. 가는 윤곽의1픽셀 틈을 닫고, 내부의 두 톤 격자와 부드러운 금속 음영을 구분했습니다. 긴 창끝이 지워지는 초기 판별 문제를 수정했습니다.
3. 큰 실루엣8개와 바로 붙은 작은 장식만 분리해, 원본 칸을 넘은 무기 끝도 보존했습니다.
4. 발 부분을 기준으로 캐릭터별 공통 피벗을 잡고 Idle·Attack에 같은 배율을 적용했습니다. 무기 방향에 따라 피벗이 칸 중앙과 다를 수 있습니다.
5. 최근접 이웃 보간으로 배치하고 마지막 불투명 픽셀 행을 localY500에 맞췄습니다. 원본 RGB를 다시 그리거나 포즈를 보간 생성하지 않았습니다.

## 연결과 시각 검토에 남은 것

- 생성 단계에서 생긴 체격·가면·옷 주름의 미세한 변화와 루프 접합은 사용자 시각 검토가 필요합니다. 가는 무기·가시 가장자리도 실제 표시 크기로 확인합니다.
- 실제 레거시 Unity 클립 키 수는 캐릭터마다 다릅니다. 제작 참조가4프레임이라는 사실과 구분합니다.
-8프레임을 넣으면서 클립 길이를 자동으로2배 늘리지 않습니다.
- 피해·힐·실드는 전투 코루틴 지연값에서 적용됩니다. 새 핵심 포즈와 효과 시점은 Unity 연결 시 대조해야 합니다.
- Sprite slicing, PPU, 피벗, 임팩트 시점과1280×720·1920×1080 플레이 검증은 미실행입니다.
- 이번 코드 처리 승인은 새 외형/동작 시안의 최종 승인이나 Unity 연결 승인과 구분합니다.

재실행에는 Pillow·NumPy·SciPy가 필요합니다. 이번 작업의 SciPy는 작업용 임시 디렉터리에만 설치했으며 저장소/전역 환경에 추가하지 않았습니다. 스크립트는 원본 해시가 달라지면 중단합니다.
