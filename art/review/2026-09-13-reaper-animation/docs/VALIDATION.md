```
FAIL  sheetSha256 does not match the file on disk
FAIL  sheet regions differ from the source frames: 04.png
8 passed, 3 failed, 0 skipped   → 종료 코드 1
```

유도한 결함 3개를 모두 잡았다.

## 2. 검증하지 못한 것

- **거두는 자 애니메이션 자체** — 프레임을 만들지 못했으므로 검증할 대상이 없다.
  시각 검수 항목(동작 가독성, 준비·타격·회복 구분, 반복 경계, 손-무기 접점 유지)은
  전부 **미검증**이다
- **미리보기 페이지의 다른 브라우저** — 확인한 것은 데스크톱 앱 내장 브라우저 하나뿐이다.
  Safari·Firefox·모바일은 미확인
- **`file://` 직접 열기** — `fetch('manifest.json')`이 파일 프로토콜에서 막힌다.
  로컬 서버가 필요하며, 페이지에 그 안내 메시지를 넣어 두었다. 실패 경로 자체는 미확인
- **생성 프롬프트의 실제 결과** — 이미지 생성 도구가 없어 한 번도 돌려보지 못했다.
  프롬프트는 기존 wave-a 프롬프트 문형을 따른 **초안**이며 검증되지 않았다
- **12프레임·10프레임 시트의 실제 조립** — 도구는 임의 격자를 지원하지만
  4×3, 5×2 배치는 입력이 없어 실물로 시험하지 못했다. 8프레임 4×2만 검증했다

## 3. 재실행 방법

```bash

  --sheets art/production/graphics-remake/wave-a/animation-8f/2026-09-10/normalized_v1 \
```

## 17. 96프레임 전수 확인 — 출처와 범위

**출처:** Codex 가 별도 세션에서 먼저 확인해 수치를 전달했다.
**이 문서 작성자는 같은 검사를 직접 재실행해 네 값이 모두 일치함을 확인했다.**
아래 수치는 재현된 값이다.

**범위:** `normalized_v1/frames/**` 의 **파일명이 숫자인 PNG 96개 전부**
(대기 6종 48 + 공격 6종 48). 3차의 중복 검사는 대기 48프레임뿐이었다.

| 검사 | 결과 |
|---|---|
| 숫자 이름 PNG 개수 | 96 |
| PNG **파일** SHA-256 중복 | 0 |
| **RGBA 픽셀** SHA-256 중복 | 0 |
| 알파 bbox 의 셀 가장자리 접촉 | 0 |
| 하단 여백 | 96프레임 모두 11px (값 집합이 `{11}` 하나) |

파일 해시와 픽셀 해시를 나눈 이유는, 메타데이터만 다르고 픽셀은 같은
프레임을 파일 해시가 놓치기 때문이다. **둘 다 0이다.**

### 재현 절차

```bash
python3 - <<'EOF'
import hashlib, numpy as np
from PIL import Image
from pathlib import Path
base=Path('art/production/graphics-remake/wave-a/animation-8f/2026-09-10/normalized_v1/frames')
files=sorted(p for p in base.rglob('*.png') if p.stem.isdigit())
fh,ph,edge,bottoms={},{},[],set()
for p in files:
    fh.setdefault(hashlib.sha256(p.read_bytes()).hexdigest(),[]).append(p)
    im=Image.open(p).convert('RGBA')
    ph.setdefault(hashlib.sha256(im.tobytes()).hexdigest(),[]).append(p)
    a=np.asarray(im.getchannel('A'))>0; ys,xs=np.nonzero(a)
    if xs.min()==0 or ys.min()==0 or xs.max()==im.width-1 or ys.max()==im.height-1: edge.append(p)
    bottoms.add(im.height-1-ys.max())
print(len(files),
      sum(len(v)-1 for v in fh.values() if len(v)>1),
      sum(len(v)-1 for v in ph.values() if len(v)>1),
      len(edge), sorted(bottoms))
EOF
# 기대 출력: 96 0 0 0 [11]
```

새 도구 파일은 만들지 않았다.
