# v3 — 흰 외곽 배경 정리 후보

- 기준: `../rgba_v2/`의 8프레임. 기존 파일은 보존했다.
- 8프레임 모두에서 투명 영역과 연결된 밝은 무채색 배경 성분을 제거했다.
- 조건: RGB 최솟값 >195, HSV 채도(0~255) <35, y≥150, 8방향 연결.
- 각 프레임의 외곽 인접 검출 수는 177/173/169/158/150/126/177/167에서 모두 0이 됐다.
- 제거한 성분 밖의 RGBA 픽셀과 y<150의 낫 하이라이트는 완전히 동일하다.
- 자세·크기·위치·프레임 순서·200ms 지속시간은 바꾸지 않았다.
- 기존 조립·기술 검사 10/10 통과. 전후 F1/F5 3배 비교 보드가 같은 폴더에 있다.
- 낫의 움직임 문제는 아직 남아 있다. 이 버전은 전체 동작 검수 통과본이 아니다.

낫 위치만 요청한 내장 이미지 편집 결과는 몸과 옷까지 크게 달라져 채택하지 않았다.
그 결과와 측정 근거는 `../rejected_attempts/`에 보관했다.
