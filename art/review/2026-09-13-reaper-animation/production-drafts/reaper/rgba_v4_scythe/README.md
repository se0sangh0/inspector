# v4 — 낫 부분 위치 보정 시안

- 사용자 승인: 2026-09-14, 기존 픽셀의 낫 윗부분 이동 보정.
- 기준: `../rgba_v3_fringe/`. 기존 버전과 원본은 보존했다.
- 384×512 RGBA 8프레임, 1536×1024 시트, 200ms×8=1600ms 반복.
- F2~F8의 날·상단 결합부만 각각 −3/−7/−9/−4/−1/+4/+6px 이동했다.
- 목재 자루의 y125~141은 기존 픽셀을 nearest 방식으로 재배치해 원래 y142 자루에 연결했다.
- F1 전체와 모든 프레임의 y≥142(몸·옷·손·하단 자루)는 v3와 완전히 동일하다.
- 나머지 영역도 낫 마스크 밖 기존 불투명 픽셀은 동일하며 몸과의 새 겹침은 0이다.
- 날 픽셀 자체는 원래 색과 형태를 그대로 정수 이동했다. 이미지 생성이나 새 색칠은 하지 않았다.

## 확인 결과

- 기술 검사 10개 통과, 실패·건너뜀 0개.
- 별도 저장 파일 비교: 시트와 8개 프레임 일치, 보호 영역 보존, 셀 경계 접촉 없음.
- 날끝의 F8→F1 이동: 9px → 3px. 보정 후 주기 안 최대 단계 4px 이내.
- 앞선 독립 검수의 손 이동값을 기준으로 날끝 상대 위치 편차는 최대 2px.
- 목재 연결부 확대 보드에서는 틈이나 이중 자루가 보이지 않았다. 독립 동작 검수는 Claude에 요청했다.
- 회백색 외곽 잔여는 v3 상태를 유지했다. 이 보정은 그 부위를 다시 바꾸지 않았다.
- Codex 별도 브라우저에서 1배·정상 속도 재생 중 F8 도달과 F1 복귀를 순서대로 확인했다.
- 1배 어두운/밝은 배경에서 같은 F3를 확인했고 브라우저 오류 로그는 0개였다.
