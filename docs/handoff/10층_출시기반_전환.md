- 작성일: 2026-09-27
- 요청: 실제 화면 조작까지 검증하고, 10층 구조로 출시 준비를 시작한다.
- 상태: 코드·자동 검증·Mac 개발 빌드와 주요 실제 조작 검증 완료. 전체 정상 난이도 완주는 별도 검증 대상.
- 기준: [00 §4](https://app.notion.com/p/3af6aef5baac817f900ee6e002a1a199),
  [03 §1](https://app.notion.com/p/3af6aef5baac812e9f0de26468f2e2fc),

- 이 문서는 10층 실행 기반의 구현 상태다. 출시 완료나 전체 정식판 명세의 완성을 뜻하지 않는다.

## 1. 이번 변경

| 구간 | 구현 |
|---|---|
| 1층 | 시작 지점 |
| 2~8층 | 층마다 3갈래, 실제로 방문한 타입이 3회 연속되지 않게 다음 후보 조정 |
| 8층 완료 | 결과 열람을 마친 뒤 페이드와 함께 9층 자동 진입 |
| 9층 | 화톳불 정비, 방문당 한 번 회복 |
| 9층 정비 확인 | `성소로 향한다` 단일 버튼 |
| 10층 | 거두는 자 보스, 기존 승리·전멸 보고서와 런 마감으로 연결 |

생성 결과는 10층·24노드다. 원본 씬에 10개 행이 이미 있어 씬 파일은 변경하지 않았다.
튜토리얼의 기존 3노드는 유지했다.
한 장소가 진행 중이거나 자동 이동 중일 때 다음 노드를 누르지 못하게 했다.

일반 전투는 기존 고블린·약탈자의 조합을 08 §1-2에 따라 추첨한다.
전반 2~4층과 후반 5~8층의 가중치 표는 문서의 플레이테스트용 값을 사용했다.
동일 조합의 연속 추첨을 막고 새 런에서 추첨 이력을 초기화한다.
새 적·보스나 HP·피해·보상 수치는 만들지 않았다.

선택지 사건은 실제 효과가 구현된 후보 중 아직 보지 않은 것을 추첨한다.
합류·다음 전투 스택·성향 재굴림·오브제·오염도 같은 미구현 효과를 가진 사건은 제외한다.
파티 상태 조건부 처리가 빠진 EVT-17과 구형 단말 문안이 남은 EVT-05도 보류했다.
사건 수치나 미결 서사 티어를 이번 변경으로 확정하지 않았다.

보고서의 탐사 구역에는 경작지를 추가했다.
타이틀의 시작 버튼을 초기 선택으로 연결해 키보드 진입 경로를 보완했다.
개발 앱에서 Enter로 시작하기 진입을 확인했다.

## 3. 실제 화면 검증 결과

사용자 잠금 해제 후 Finder에서 별도 개발 앱을 전면 실행해 마우스·키보드로 검증했다.
기본 해상도는 1280×720이다. 아래 디버그 보조 구간은 정상 난이도 완주로 세지 않는다.

| 실제 조작 | 확인 결과 |
|---|---|
| 시작 버튼·Enter, 오프닝 진행 | 지도 진입 정상 |
| 일반 전투 | 디버그 없이 첫 전투 7턴 승리, 결과 +20, 사건 기록 1건 |
| 카드 선택·취소·재선택 | 0에서 -1→+2는 2, 음수 카드 재선택 시 1, Space·턴 종료 버튼 정상 |
| 관찰창·수첩 | 아래 버튼이 화면 안에 있고 클릭 가능, 관찰창은 Space로 닫히지 않음 |
| KO→EN→KO | 지도·수첩·정비 문구 왕복 전환, 영어 수첩 줄바꿈 정상 |
| 까마귀 선택지 | 선택·결과 확인을 연속 클릭해도 사건 기록은 1건 |
| 8층→9층 | 결과를 닫은 뒤 자동 진입, 별도 경로 클릭 불필요 |
| 정비·파티 편집 | 편집 복귀 후 회복 중복 없음, 캐스터 HP 45→75가 보스 진입까지 유지 |
| 9층→10층 | 한국어·영어 단일 이동 버튼 확인, 보스 1체 진입 |
| 승리 보고서→다음 탐사 | 확인 후 새 런 2차, 수첩 비움 |
| 전멸 보고서→타이틀 | 임무 실패 표시, 승리 질문 없음, 타이틀 복귀 |

후반 연결 검증에서는 F1 즉시 승리, 7층 건너뛰기, 적 행동 1회와 즉시 패배를 사용했다.
F1 즉시 승리는 정상 처치 정산을 건너뛰므로 보상 팝업 합계와 실제 잔액이 다르다.
이 경로는 진행·배치 검증에만 사용했고 보상 수지 검증에 사용하지 않았다.
최초 7턴 전투는 디버그 보조 없이 진행했다.

### 실제 화면에서 발견해 고친 항목

- 동적으로 만드는 Canvas의 기본 모드가 WorldSpace라서 화면 배율 설정이 건너뛰어졌다.
  관찰·수첩·보고서·결과·로딩·전환 6곳에서 Overlay 지정 뒤 배율을 설정하도록 수정했다.
  수정 전 관찰창의 계속과 수첩의 닫기가 화면 아래로 잘렸고, 수정 후 실제 클릭을 확인했다.
- NanumGothicLight SDF에 가운데점 U+00B7이 없어서 □로 보였다.
  기존 LiberationSans fallback 참조 1개를 연결했다. 문안과 원본 글꼴 파일은 유지했다.
- 까마귀 결과의 영어 `A scythe reflected ...`를 Claude 검토 결과에 따라
  `A scythe was reflected in the raven’s eyes. There is no scythe in this room.`으로 수정했다.
- 보스 승리 때 구형 엔딩 안내가 보고서와 다음 행동 화면 뒤에 남았다.
  구형 팝업을 숨기고 보고서로 직접 연결했다. 최종 재빌드의 보스 승리와 다음 행동 화면에서 겹침 제거를 확인했다.

추가 Unity 회귀 검사는 실제 640×480 batch viewport에서 생성 Canvas 6개와
모든 버튼의 화면 내 bounds, 가운데점 fallback을 검사해 30개 통과했다.
검증 하네스의 Editor 컴포넌트 생성 방식과 부동소수점 경계 오판을 먼저 수정했다.
가상 해상도 계산을 실제 720p/1080p 검증으로 세지 않았다.
개발 앱에서 1280×720 배치를 별도로 조작했다.
최종 실행의 예외·글자 누락 경고는 0건이고, 수정된 Assets 원본 31개가 빌드 사본과 일치했다.
최종 빌드의 바구니 수첩 기록에서 가운데점 표시를 직접 확인했다.
까마귀 영어 수정은 최종 빌드에 포함됐으나 마지막 재빌드 뒤 같은 무작위 사건을 다시 뽑지는 않았다.

- 새 영어 UI 문구는 Claude Opus 5.5(`claude-opus-5-5`), `max`로 짧은 표 묶음씩 검토했다.
- 단일 확인 버튼은 상태 표현과 구분해 `Head to the Sanctum`으로 재검토했다.

- 이동 안내, 화톳불 설명, 10층 진행 설명을 각각 별도 요청으로 검토했다.
- 이동 안내와 10층 설명은 통과했다. 화톳불 설명의 `화툿불`은 `화톳불`로 고쳤다.
- 실행 결과의 초기화 메타데이터에서 요청 모델과 실행 모델을 비교했다.
- 문단별 요청 방식과 Gemini 오타 검수 역할을 `CLAUDE.md`에 기록했다.
- 화면에 표시된 전투 안내와 까마귀 결과도 각각 별도 문단으로 Gemini 3.8 검수를 통과했다.
- 까마귀 결과 1문단은 Claude Opus 5.5 max의 실제 실행 모델을 확인한 뒤 반영했다.

- 경로 카드·진행도 맵 분리는 후속 구현 완료. [새 구현과 삽화 상태](이동경로_카드와_진행도맵.md)를 따른다.

- 경작지 등 구간별 정식 배경과 추가 해상도·언어별 시각 검수. 선택지 카드의 회색 임시 이미지도 교체 대상이다.
