## Unity 연결 준비

기존 AudioManager·SoundDatabase의 BGM/SFX 경로와 별도로 NarrationPlayer를 추가했다.
현재 연결은 다음과 같다.

- 전용 음성 AudioSource와 87개 문안의 로컬 클립 카탈로그. 한 번에 한 음성만 재생한다.
- 음성 음량·음소거를 BGM/SFX와 독립적으로 저장한다.
- 오프닝 문서, 사건 본문과 확정 결과, 관찰 창의 표시 시점에 연결한다.
- 경로·사건 선택지는 초점이나 다시 듣기로 한 항목씩 읽어 중첩을 막는다.
- 화면을 닫거나 다음 문단·씬으로 이동하면 해당 음성을 중지한다.
- 언어 전환 시 이전 언어 음성을 중지한다. 영어 파일이 없으면 한국어 파일을 대신 재생하지 않는다. 오프닝은 현재 문서의 새 언어 음성을 다시 요청하고, 그 밖의 화면은 다음 표시·초점에서 요청한다.
- 타이핑을 빨리 표시하는 입력과 화면을 넘기는 입력을 구분한다. 타이핑 완료만으로 중복 음성을 시작하지 않는다.
- 런 보고서·수첩의 동적 수치는 정적 음성 범위와 구분해 재생 방식을 정한다.

초기 실제 WAV 3개로 Unity PlayMode 검사 26개를 통과했다. 연속 재생·취소 검사를 더한 재검증에서는 30개를 통과했고, 사건·경로 화면 연결 검사 15개도 통과했다.
최신 macOS Universal 미리보기는 43개 음성·48개 사용 위치를 포함한다. 빌드 오류 0개·경고 1개이며, 경고는 Unity Cloud 인증 정보가 없어 네이티브 심볼 업로드를 생략한 것이다.
43개 클립을 실제 Unity에서 불러와 길이·주파수·채널·로드 상태·카탈로그 연결을 검사했고 모두 통과했다. 남은 44개는 미제작으로 구분한다.
30개 음성 미리보기에서 음성 슬라이더 이동·창 재열기 후 값 유지·오프닝 두 문서 이동을 확인했다. 최신 43개 빌드도 별도 앱으로 실행해 타이틀·시작·오프닝 두 문서 이동을 확인했다. 이후 추가 화면 이동은 Mac 잠금으로 중단됐다.
음성 라벨의 글씨 차이를 발견해 기존 효과음 라벨의 서체·크기·굵기를 따르도록 수정했다. 최종 미리보기 실행 화면에서 동일한 크기와 겹침 없는 배치를 확인했다.
1.1초 뒤 사라지는 기록 갱신 알림은 자동 낭독하지 않는다. 화면 이동 시간을 늘리거나 음성 문장을 중간에 자르지 않는다.
파일 길이·형식·원문/수정본 해시는 검증하지만, 전체 발음과 잘림의 청취 검수는 완료하지 않았다.
웹 무료 사용이 불가능하거나 지정 모델을 사용할 수 없으면 과금 경로나 다른 모델로 임의 전환하지 않는다.
