## 1. 실행 전에 알아야 할 것 — CLI 버전

`codex exec`가 **실패하면서 종료 코드 0을 반환한다.** 종료 코드를 성공 판정에
쓰지 않는다.

```
$ codex exec "echo test" ; echo "EXIT=$?"
Error loading config.toml: invalid type: map, expected a boolean
in `features`
EXIT=0
```

원인은 설정 파일이 아니라 **CLI 버전**이다. 2026-09-12에 확인한 값이다.

| 경로 | 버전 | 설정 로드 |
| --- | --- | --- |
| `~/.local/bin/codex` (`which codex`) | 0.150.1 | 실패 |
| `/Applications/ChatGPT.app/Contents/Resources/codex` | 0.153.4 | 정상 |

`~/.codex/config.toml`의 `[features.context_management]` 블록은 ChatGPT 앱이 써 넣은
것이고 0.153.4는 이 형식을 이해한다. 0.150.1만 `features` 아래를 전부 불리언으로
기대해서 깨진다. **설정 파일을 고치지 않는다.** 고치면 앱 쪽이 틀어질 수 있다.

해결은 둘 중 하나다.

```bash
npm i -g @openai/codex@latest
```

또는 이번 실행에만 번들 바이너리를 직접 지정한다.

```bash
"/Applications/ChatGPT.app/Contents/Resources/codex" exec "..."
```

### 4.3. 번역 키 개수

```bash
python3 - <<'EOF'
import re
src = open('site/preview/index.html', encoding='utf-8').read()
for lang in ('zh', 'en', 'ko'):
    m = re.search(r'\n        %s: \{(.*?)\n        \}' % lang, src, re.S)
    keys = re.findall(r'\n          ([a-zA-Z]+):', m.group(1))
    print(lang, len(keys))
EOF
```

세 줄의 숫자가 같아야 한다. 제거 전 값은 83이었으므로 75가 되어야 한다.

## 5. 배포는 별도 승인

이번 범위는 **로컬 구현과 검증까지**다.

`git commit`, `git push`, GitHub Pages 배포는 사용자가 화면 검수 결과를 본 뒤
따로 승인한다. `main`의 `site/preview/**`가 바뀌면 워크플로가 자동 배포하므로
푸시 자체가 공개 배포다.
