## 2. 확인한 문제와 반영

| 문제 | 수정 결과 |
|---|---|
| 같은 사건의 다른 선택을 다시 호출하면 효과가 재적용됨 | 런별 확정 결과를 보관하고 비용·효과·기록을 반복하지 않음 |
| 결과가 없는 유료 선택에서도 비용 차감 | 유효한 결과가 있는지 먼저 확인 |
| 비용 부족을 변화 없는 정상 결과로 표시 | 선택 화면 유지, 지불 가능 여부 다시 확인 |
| 확인 연타로 종료 이벤트 반복 | 결과 확정 후 한 번만 종료 |
| 재바인딩 때 확정 결과를 잊고 선택지 재표시 | 기존 결과와 확정 당시 상태 피드백 복원 |
| 이벤트 소진 시 같은 런에서 다시 순환, 층 제한 무시 | 후보가 없으면 null 반환, 새 런에서만 초기화 |
| 현재 6층 화면이 정식판 19종 전체를 추첨 | 화면 진입은 EVT-01만 런당 한 번 선택 |
| EventPanel이 이미 1-base인 층에 다시 1을 더함 | 실제 선택 층 그대로 사용 |
| 수첩의 구역이 좌·중·우 선택 위치를 뜻함 | `[제 N구역 현장 기록]`의 N을 실제 층으로 표시 |
| 빈 제목·본문이 빈 줄로 출력 | 빈 항목 생략 |
| EVT-01은 서사 결과문만, 화톳불은 제목만 기록 | 확정된 장소·조치·결과·동료별 실제 변화량 기록 |
| 동료를 같은 직업명만으로 식별 | 수첩에서 표시 직업명과 런 내 최소 두 자리 번호 사용 |
| 전투 소실 동료가 사건 기록에서 빠짐 | 같은 전투 사건에 조건부 소실 줄 추가 |
| 영혼석 획득량이 지출 후 잔액으로 표시 | 시작 자금을 제외한 런 총획득량 집계 |
| 보상 가산이 수거 연출 완료까지 지연 | 먼저 지급하고 연출에는 재화 콜백을 넣지 않음 |
| 전멸 보고서에도 마지막 질문 노출 | 승리 보고서에서만 질문 표시 |
| 상태 줄 증가로 여러 사건이 페이지를 넘침 | 실제 텍스트 높이를 측정해 다음 사건을 새 페이지에 배치 |

상세 전투 행동 로그는 이미 `GameLogService`로 분리돼 있었다.
이를 수첩에 복사하거나 지우지 않았다. 기존 전투 계산과 수치는 유지했다.
동료의 기록 번호는 고용 후보 생성으로 소비하지 않는다.
처음 배치된 동료에게 01~04를 주고, 실제 기록되는 합류 인원부터 이어 준다.
같은 동료의 부활·이동에서는 번호를 유지한다.

## 3. 문단별 번역 재검토

- 모델: `claude-opus-5-5` · 요청 추론: `max`
- 실행기: 별도로 실행한 Claude Code 2.1.280. 기본 설치본은 바꾸지 않았다.
- 10개 문단·짧은 표 묶음, 총 47개 항목을 검토했다.
- 각 호출의 응답 모델과 `modelUsage`가 모두 지정 모델과 일치했다.
- 10개 모두 정상 종료했다. 구역 용어는 별도 한 문구 검토로 `Zone`에 맞췄다.
- 번역 23개를 추가하고 기존 번역 5개를 수정했다.
- 새 번역은 `LocalizationTable.Notebook.cs`에서 기존 표와 함께 등록한다.
- 한국어 기획 문장은 원문을 복사했다. 바구니 수첩 문장은 정본의 가운뎃점 표기를 맞췄다.

기존 번역의 수정은 다음과 같다.

1. 야영지 수색: 흩어져 물건을 조사한다는 내용을 반영한다.
2. 바구니 관찰: 내용물이 안쪽에서 쏟아져 나온 방향을 바로잡는다.
3. 영혼석 합계: 공통 용어 `Soulstones`의 복수형을 사용한다.
4. 전투 결과: 공식 기록에 맞춰 `Slew`를 `Killed`로 바꾼다.
5. 야영지 본문: 재 아래쪽의 온기와 도구에 묻은 흙을 정확히 옮긴다.

처음의 큰 요청은 구버전 실행기 거절·시간 초과·사용자 지시에 따른 중단으로
완료되지 않았다. 그 호출들은 검토 완료에 포함하지 않았다.
문단별 검토는 완료된 결과부터 원문·변수·용어를 대조해 통합했다.
47개 항목 밖의 모든 문구를 의미 검수했다고 주장하지 않는다.
등록된 전체 번역표의 숫자 변수 일치는 별도로 검사했다.

  옮기는 작업은 아직 하지 않았다. 현재는 기존 사건 노드 위치에서 표시된다.

  미구현 효과가 남아 있다. 현재 6층 화면에서는 이 이벤트들을 선택하지 않는다.

- 종이 넘김 연출과 실제 해상도별 시각 검수는 후속 작업이다.
