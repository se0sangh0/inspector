- 후속: 실제 화면에서 발견한 닫기 중복을 수정하고 TTS46 빌드의 실제 클릭 검증을 마쳤다. [최신 기록](아이콘_실제화면_검증_및_TTS46_2026-09-28.md)을 우선한다.
- 기준: 사용자의 아이콘 제작 및 후속 작업 요청, 그래픽 재제작 마스터 §1-2·§2-4.

## 플레이어 화면에 반영한 내용

영혼석과 마석 표시, 설정 버튼, 조사관 수첩 버튼, 설정·로그·수첩의 닫기 버튼에 새 아이콘을 연결했다.
기존 버튼의 배경·클릭 영역·동작과 재화 수량 텍스트를 유지했다.
장식 그림은 클릭을 가로채지 않으며 반복해서 열어도 중복 생성하지 않는다.
리소스가 없으면 기존 화면을 유지한다.

도움말·핵심 단서·뒤로는 현재 사용처가 없어 준비 에셋으로만 임포트했다.
아이콘을 쓰기 위해 새 기능이나 버튼을 추가하지 않았다.

영혼석과 설정은 32픽셀에서 더 잘 보이도록 내장 image_gen으로 v2를 만들었다.
원본은 보존했다. Unity 표준 임포트에서 8종 모두 64×64, Sprite/Single, Point, 무압축으로 설정했다.
임포트된 8종의 바깥 8픽셀은 알파값 0임을 확인했다.
생성 원본 전체를 이진 알파로 수정했다는 뜻은 아니다.

## 연결 파일

- `Assets/Scripts/UI/SystemIconArt.cs`: 아이콘 적용·장식 생성·누락 시 기존 UI 유지
- `Assets/Scripts/UI/LeftPanelView.cs`: 재화 행의 정확한 `Icon` 자식과 설정 `Icon_Image` 연결
- `Assets/Scripts/Log/InvestigatorNotebookController.cs`: 수첩 열기·닫기
- `Assets/Scripts/Node/RouteSelectionPanel.cs`: 경로 화면의 수첩 버튼
- `Assets/Scripts/Settings/SettingPopup.cs`, `Assets/Scripts/Log/LogPopup.cs`: 닫기 장식
- `Assets/Editor/SystemIconImport.cs`: 원본을 보존하는 표준 임포트 설정
- `Assets/Resources/RemakeV1/SystemIcons/`: 8개 PNG와 Unity GUID·임포트 설정

기존 프리팹·씬을 대량 재직렬화하지 않았다.
독립 검토에서 재화 자식 이름이 `Icon_Image`가 아닌 `Icon`임을 확인해 수정했다.
라벨이 재열기 때 계속 줄어든다는 초기 검토 의견은 원문 확인으로 철회했다.
실제 재열기 검사에서도 라벨 영역이 유지됐다.
