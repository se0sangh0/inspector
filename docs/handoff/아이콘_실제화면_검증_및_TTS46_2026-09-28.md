작은 설정 아이콘을 버튼 왼쪽 끝에 고정해 글자와 떨어뜨린 배치를 수정했다.
아이콘과 글자를 하나의 가로 묶음으로 가운데 정렬하며, 언어가 바뀌면 글자 너비에 맞춰 함께 이동한다.

## 발견한 문제와 수정

이전 TTS45 빌드의 설정·로그를 실제로 열었을 때 닫기 표시가 겹쳤다.
기존 버튼 그림의 X와 글자 X를 남겨 둔 채 새 아이콘을 우측에 더한 것이 원인이었다.

`SystemIconArt.EnsureGlyphOnlyIcon`이 기호만 있는 닫기 버튼을 구분한다.
기호가 없는 기존 기본 버튼 배경으로 교체하고 X 글자를 숨긴다.
새 닫기 아이콘은 가운데 하나만 표시한다.
마우스를 올리거나 누를 때도 예전 X 그림이 돌아오지 않도록 SpriteSwap 상태를 정리했다.
버튼의 크기·클릭 영역·이벤트·TargetGraphic 컴포넌트는 유지했다.
수첩처럼 `닫기`라는 문구가 있는 버튼은 기존 문구와 우측 아이콘을 유지했다.

수정 파일은 `SystemIconArt.cs`, `SettingPopup.cs`, `LogPopup.cs` 3개다.
이미지 원본, 번역 문구와 씬·프리팹 파일은 이번 수정에서 바꾸지 않았다.

## 실제 화면 확인

Codex 화면 조작 도구로 새 앱을 직접 실행하고 다음을 확인했다.

- 타이틀 설정창에 닫기 아이콘이 하나만 보인다.
- 아이콘을 직접 클릭하면 닫히며 다시 열어도 중복되지 않는다.
- 영어 설정 라벨이 잘리지 않고 표시된다. 검증 후 한국어로 되돌렸다.
- 오프닝 두 문서를 거쳐 경로 카드 화면에 진입한다.
- 재화 항목을 펼치면 영혼석·마석 아이콘과 수량이 표시된다.
- 수첩 아이콘 위를 클릭해 수첩을 열고 닫을 수 있다.
- 로그창의 닫기 아이콘이 하나이며 클릭하면 경로 화면으로 돌아온다.
- 설정 아이콘 위 클릭으로 게임 중 설정창을 열고 닫을 수 있다.
- 확인 범위에서 실행 예외·글리프 누락 진단은 0개다.

이 결과는 해당 UI 확인 범위의 완료다. 정상 난이도 10층 완주나 전체 음성 청취 검수를 뜻하지 않는다.
