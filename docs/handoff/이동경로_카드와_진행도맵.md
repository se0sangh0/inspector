# 이동 경로 카드와 진행도 맵

- 날짜: 2026-09-27
- 요청: 현 노드맵을 기획의 이동 방식으로 변경한다.
- 정본: [03 §1-1B](https://app.notion.com/p/3af6aef5baac812e9f0de26468f2e2fc), [15 I0~I5](https://app.notion.com/p/3af6aef5baac8185866ff29253c2e69f).
- 적용 범위: 사용자가 선택한 정식판 10층 진행. 6층 시연 전용 장소·단서 배치를 가져오지 않는다.
- 상태: 구현·자동 검증·실제 조작 검증 완료. 2026-09-27 사용자의 “적용해서 빌드까지” 지시에 따라 현재 화면을 적용했다.

## 플레이어 화면

1. 일반 구간에서는 다음 층으로 이어지는 경로 카드 3장을 본다.
2. 카드에는 제목·환경 설명·징조와 경로 그림만 표시한다.
3. 정확한 노드 타입·적 구성·보상·사건 결과·확률은 선택 전에 보이지 않는다.
4. 카드 전체를 클릭하면 하나의 경로를 선택한다. 선택하지 않은 후보는 닫힌다.
5. 선택 직후 경로 원문을 수첩에 기록하고 실제 장소를 공개한다.
6. 결과 확인 뒤 다음 세 장을 준비한다.
7. 진행도 맵은 현재 위치·실제로 선택한 경로·공개된 장소와 고정 목적지만 보여 준다.
   선택한 경로 사이에는 연결선을 그린다. 방문하지 않은 후보는 표시하거나 클릭할 수 없다.
8. 8층 방문 완료 뒤 9층에 자동 진입한다. 9층 정비 뒤에는 기존 단일 확인으로 10층에 진입한다.

첫 카드 안내는 선택을 막지 않는다. 첫 경로 기록 성공 뒤 수첩 버튼을 한 번 강조한다.
짧은 이동 안내 동안 선택한 카드만 남고, 열린 수첩·모달을 닫은 뒤 장소 진입을 이어간다.
이동 안내 완료 플래그는 새 런에서 초기화하지 않는다.

## 후보와 기록

- 숨은 노드 생성 가중치와 10층 구조는 이전 구현을 유지한다.
- 이벤트 내부 결과도 경로 준비 시 한 번 추첨한다. 카드·맵 열람과 언어 변경으로 다시 뽑지 않는다.
- 이전 두 방문과 같은 타입의 3연속을 막는 다음 층 조정 뒤 경로 정보를 준비한다.
- 엘리트가 예정된 경로와 후반 일반 전투에는 명시적 위험 경고를 표시한다.
  경고 단계명과 적·보상·수치를 노출하지 않는다.
- 카드 문구는 노드 타입과 1:1로 묶지 않는다. 같은 환경 카드가 서로 다른 장소로 이어질 수 있다.
- 수첩의 RouteSelected, LocationRevealed, 후속 전투·사건·서비스 결과는 같은 구역 헤더 아래 모인다.
- 제목·환경·징조 원문을 번역 키로 보존하므로 기록 후 언어를 바꿔도 같은 정보를 읽을 수 있다.
- 9층과 10층은 경로 3택 기록을 만들지 않고 실제 장소 공개 기록만 추가한다.

## 파일과 콘텐츠 상태

- NodeSystem.Routes: 기존 OnNodeClicked·완료 처리·9/10층 자동 이동에 새 화면을 연결한다.
- RouteSelectionPanel: 카드·진행도 맵·수첩 버튼·첫 안내를 표시한다.
- RouteCatalog + Resources/Routes/RouteCatalog.json: 환경별 카드와 경고 문구를 보관한다.
- RunRecord + InvestigatorNotebookController: 경로·장소를 중복 없이 저장하고 같은 층의 기록을 묶는다.
- LocalizationTable.Routes: 문단 단위 검토 결과를 반영한다.

기존 숲·협곡 경로 그림 6장을 원본 PNG와 같은 내용으로 Resources/Routes에 복사했다.
기존 art/review의 review_pending은 당시 이력으로 보존했다.
사용자가 현재 화면의 적용과 빌드를 지시해 6장의 현재 통합을 승인한 것으로 기록했다.
적용 범위와 파일 해시는 art/review/2026-09-27-route-map-application/manifest.json에 남겼다.
원본 그림과 기존 씬·프리팹의 GUID는 유지했다.

숲·협곡 카드 6개는 [16-E](https://app.notion.com/p/3c06aef5baac8133a093dd0f57a043d4)의
기존 세 줄 문구를 사용한다. 해당 문서의 6층 고정 장소·단서 계약을 10층 랜덤 구조에 이식하지 않는다.
경작지 카드 3개와 강한 경고는 03의 공개 범위 안에서 작성한 구현 초안이다.
경작지에는 확정 삽화가 없어 방향을 표시하는 간이 선도를 사용하며 최종 일러스트로 세지 않는다.

## 검증

자동 검사는 별도 Unity 6000.3.9f1 사본의 실제 GamePlayScene PlayMode에서 실행했다.
빌드와 API 검증 사본에는 각각 전용 bundle identifier를 지정했다.

- 경로 UI·후보 유지·정보 숨김·수첩 차단·연타·같은 구역 기록·페이지 분할을 포함해 26개 검사 통과.
- 뒤섞인 경작지 카드에서도 실제 문구와 도식 방향이 일치하는 검사.
- 진행도 맵의 지역 표제가 다음 후보 지역이 아니라 현재 위치를 가리키는 검사.
- 기존 10층 구조·인카운터·9층 자동 이동·10층 보스 연결 회귀 124개 통과.
- Mac ARM64 개발 빌드 성공. 최종 UI 실행의 예외·글리프 누락 경고 0건.
- 마지막 빌드에서 뒤섞인 경작지 카드의 문구·도식 방향과 현재 지역 표제를 재확인했다.
- 새 탐사로 돌아가 카드 화면 초기화와 최초 안내 비반복을 확인하고 앱을 열어 두었다.

실제 개발 앱에서는 다음을 조작했다.

- 1280×720: 카드 3장·읽기 전용 맵·수첩 열람·뒤쪽 입력 차단·연속 클릭.
- 한국어→영어 카드 표시, 후보가 바뀌지 않는지 확인.
- 경로 선택 뒤 전투 진입, 결과 확인 후 다음 카드 생성.
- 수첩에 선택 경로·환경·징조·공개 장소·전투·현장 관찰이 한 구역 아래 표시됨.
- 강한 경고 카드 선택 뒤 엘리트 진입과 선택한 경로만 남는 맵 확인.
- 1920×1080: 숲·협곡·경작지 카드 배치와 8층 시설 종료→9층 정비→10층 보스.

이 조작 검증에서는 개발 도구의 즉시 승리와 층 이동을 사용했다.
새 경로 UI로 정상 난이도 10층을 완주했다는 뜻은 아니다.

초기 빌드의 경작지 Graphic에 CanvasRenderer가 누락된 오류를 로그에서 찾고 수정했다.
하네스가 늦게 구독해 놓친 초기화 오류도 전체 실행 로그로 별도 확인했다.
경작지 도식 방향·진행도 맵 지역 표제는 실제 화면 검토 뒤 추가 회귀 항목으로 남겼다.
