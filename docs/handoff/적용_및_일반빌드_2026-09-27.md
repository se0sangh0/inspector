# 경로 화면 적용 및 일반 빌드

- 사용자 요청: “적용해서 빌드까지 하죠”
- 날짜: 2026-09-27
- 현재 경로 UI와 숲·협곡 삽화 6장을 적용했다. 경작지 간이 도식도 현재 상태로 포함했다.
- 이전 개발용 앱과 구분해 디버그 모드가 꺼진 Mac Universal 빌드를 만들었다.

- 사용 안내: 같은 폴더의 빌드_안내.txt

Unity 6000.3.9f1, Mono, x86_64 + arm64, BuildOptions.None을 사용했다.

최종 빌드 오류는 0개, 경고는 17개다. 경고는 기존 TMP 구형 API와 미사용 필드 등에 해당한다.

원본 회사명·앱 식별자·버전은 유지하고 빌드의 표시 이름은 INSPECTOR를 사용했다.
빌드 도구는 표시 이름을 빌드 후 복원한다. 원본 ProjectSettings와 씬·프리팹을 재저장하지 않았다.

## 검증

- 전 실행에서 확인한 10층 회귀 124개 결과를 유지했다.
- 전체화면의 세로 여유 공간에서 하단 안내가 카드와 겹치는 문제를 추가로 발견했다.
- 같은 검사를 수정 전에는 실패 1개로 재현했고, 아래 기준 앵커 적용 후 경로 검사 27개가 모두 통과했다.
- 최종 일반 빌드를 실제로 열어 시작·오프닝·경로 카드 진입과 전체화면 하단 배치를 확인했다.
- F1을 눌러도 디버그 메뉴가 나타나지 않는다. 게임 어셈블리에도 DebugToolPanel과 즉시 승리 훅이 없다.
- 실제 실행 로그의 예외와 글리프 누락 경고는 0개다.
- 실행 파일에 x86_64와 arm64가 모두 있으며 서명 무결성 검사와 ZIP CRC 검사를 통과했다.
- 실행 검증 기기는 Apple Silicon이다. Intel 기기 실행은 미검증이다.
- 임시 서명(ad-hoc)이며 Apple 공증·스토어 업로드는 수행하지 않았다.
- Windows 지원 모듈이 설치되지 않아 Windows 실행 파일은 만들지 않았다.

## 재빌드

Assets/Editor/InspectorPlayerBuild.cs를 추가했다.
Unity 메뉴 Tools → INSPECTOR에서 Mac Release와 Windows Release를 선택할 수 있다.
각 플랫폼의 빌드 지원 모듈이 필요하다. 경로 데이터·그림·씬이 누락되면 빌드를 중단한다.
배치 실행은 InspectorPlayerBuild.BuildMacRelease 또는 BuildWindowsRelease를 사용한다.
INSPECTOR_BUILD_PATH와 INSPECTOR_BUILD_REPORT로 출력 위치를 지정할 수 있다.
