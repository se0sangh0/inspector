- 상태: 소스 검토, 패널 누락 회귀 수정, Unity 검사와 Mac 재빌드 완료

## 추가 수정

장소에 진입하면 다음 선택을 잠그지만, 패널 연결이 없을 때 잠금을 풀지 않는 경로가 있었다.
화톳불·용병소·교회 패널 누락과 사건창 생성 실패가 대상이다.
실제 게임 씬의 세 패널 연결은 유효하다.
이 수정은 연결 누락이나 대체 씬에서의 진행 정지를 막는다.

`NodeSystem`의 실패 분기를 각 장소의 기존 종료 처리에 연결했다.
화톳불은 본편의 10층 자동 진입과 튜토리얼 종료 처리를 함께 유지한다.
게임 문구·번역·확정 설정과 정상 패널 흐름은 바꾸지 않았다.

  수정 전 6개 통과·5개 실패, 수정 후 11개 통과·실패 0·실행 오류 0이다.
  사건창 생성 실패, 용병소·교회 잠금 해제, 화톳불 누락 후 10층 보스 진입을 포함한다.
- 변경·신규 Assets 파일 187개의 검증 사본과 원본 SHA-256이 일치한다.
- 신규 에셋의 `.meta` 누락과 GUID 충돌, 잘못된 JSON은 없다.
- WAV 46개는 24kHz·모노이며 길이 합계는 451.80초다.
- 변경 문서의 로컬 링크와 직접 작성한 파일의 Git 공백 검사를 통과했다.
  Unity가 생성한 `.meta`의 빈 필드 뒤 공백은 기본 직렬화 형식을 유지했다.
- Unity 6000.3.9f1 Mac Universal 일반 빌드: 오류 0·기존 경고 17개.
  Intel·Apple Silicon 구성, 앱 서명 무결성, ZIP 무결성을 확인했다.
- 새 앱을 실제로 실행해 타이틀 설정 열기·닫기, 오프닝 두 문서 이동,
  경로 카드 3장 표시, 가운데 정렬된 설정 아이콘 위 클릭과 닫기를 확인했다.
  이 확인 범위에서 실행 예외·글리프 누락은 없었다.
