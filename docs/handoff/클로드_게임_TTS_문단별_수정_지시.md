# Claude 게임 TTS 대본 수정 지시

- 작성일: 2026-09-27
- 상태: 사용자 지시에 따라 실행 중
- 목적: 현재 게임의 한국어 문안을 낭독하기 좋게 다듬고, 원문과 뜻이 달라지지 않았는지 검토한다.
- 사용자 지시: 대본 수정은 Claude를 사용하며 Claude 할당량을 가능한 한 유용한 작업에 활용한다.

## 실행 방식

1. 실제 게임에서 추출한 한국어 정적 문안 87개를 문단별로 처리한다. 사용 지점은 96개이며 같은 문안은 재사용한다.
2. Claude Opus 5.5, 추론 최대로 문단 하나를 수정한다.
3. 같은 모델과 추론 설정의 별도 요청으로 원문과 수정본을 비교한다. 사건·주체·시제·선택 행동·수치·공개 범위가 바뀌면 고친다.
4. Gemini 3.8로 그 문단의 오타·띄어쓰기만 확인한다. Gemini가 새 대본을 대신 작성하지 않는다.
5. Codex가 원문과 결과를 비교하고 반영 상태를 따로 기록한다. 검토 결과가 나왔다는 이유만으로 게임 반영 또는 녹음 완료로 간주하지 않는다.
6. 음성은 로그인된 Chrome의 AI Studio 화면에서 Gemini 3.8 Flash TTS로 제작한다. 대본과 연출은 별도 입력란에 넣는다.

## 수정 기준

- 탐사국의 단정한 문서체와 절제된 호러를 유지한다.
- 고유명사·수치·인과·부정·불확실성·의도적인 암시를 보존한다.
- 자연스러운 원문은 그대로 둔다. 새로운 장소·적·보상·위험·진실을 만들지 않는다.
- 선택지는 버튼이 수행하는 행동을 바꾸지 않는다.
- 경로 카드는 제목·환경·징조 순서를 유지한다.
- 낭독용 숫자·문장부호·띄어읽기를 다듬되, 화면의 원문과 별도로 추적한다.
- 영문 연출, XML/SSML, 감정 태그를 낭독 대본에 섞지 않는다.
- 동적 수치 서식 111개는 분리한다. 중괄호와 인자 번호를 그대로 읽는 음성을 만들지 않는다.

## 할당량과 실패 처리

- 현재 로그인된 Claude 구독 경로를 사용한다. 별도 유료 API 경로로 전환하지 않는다.
- 대본 수정과 원문 대조 검토에 할당량을 사용한다. 완료한 문단을 이유 없이 반복하지 않는다.
- 지연만으로 모델이나 추론 수준을 낮추지 않는다.
- 현재 Claude 작업은 최대 두 문단을 동시에 처리한다. Codex와 Gemini를 포함한 전체 동시 모델 작업은 네 개 이하다.
- 실패·한도 도달 시 완료된 결과를 보존하고, 실패·미완료 문단을 구분한다. 다른 모델로 자동 대체하지 않는다.
- 실행 응답의 실제 모델 ID와 요청한 추론 설정을 문단별 근거 파일에 기록한다.
- 잔여 할당량 비율은 확인되지 않았다. 실행량과 남은 계정 할당량을 혼동하지 않는다.

## 상태와 근거

작업 폴더: `_workspace/2026-09-27-game-tts/`

- `production-manifest.json`: 원문·사용 위치·해시·87개 제작 대상
- `claude-revision/<문단 ID>/01-rewrite/`: 수정 요청과 응답
- `claude-revision/<문단 ID>/02-meaning-review/`: 별도 원문 대조 검토
- `claude-revision/<문단 ID>/reviewed-script.json`: 검토된 낭독 대본
- `claude-revision-progress.json`: 문단별 완료 현황
- `gemini-script-qa/<문단 ID>/`: 오타 검수
- `gemini-qa-progress.json`: 오타 검수 완료 현황
- `codex-integration-review.json`: Codex가 실제로 확인한 문단과 반영 상태

목소리 비교는 Claude가 수정하고 Gemini가 검사한 첫 오프닝을 사용한다.
원문으로 먼저 만든 두 샘플은 비교 이력으로 보존한다. 게임에 사용할 목소리는 사용자 선택 후 확정한다.
