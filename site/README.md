# INSPECTOR 웹사이트

랜딩 페이지와 GitHub Pages 배포 파일은 이 저장소 안의 `site/`에서 관리합니다.
별도 웹 저장소를 만들지 않습니다.

- `preview/`: GitHub Pages에 공개하는 개발 시안
- `preview/assets/`: 기존 시안의 내장 WebP 10종을 내용 변경 없이 분리한 웹 이미지
- 공개 주소: [https://davi-dev.uk/](https://davi-dev.uk/)
- 배포 방식: GitHub Actions가 `preview/`를 GitHub Pages 아티팩트로 배포
- 워크플로: [`.github/workflows/deploy-pages.yml`](../.github/workflows/deploy-pages.yml)
- 개선 작업 기준: [랜딩페이지 개선 작업지시서](01_랜딩페이지_개선_작업지시서.md) · 디자인·모델 배정·검수·사용량 초과 후 Luna 전환 규칙

현재 [`preview/index.html`](preview/index.html)은 한국어·영어·중국어 번체를
한 페이지에서 바꾸는 공개 개발 시안입니다. 영상과 일부 삽화 자리는
각 언어의 설명용 문구로 남아 있습니다.

브랜드 정본은 `art/brand/`, 그래픽 검토 원본은
`art/production/graphics-remake/`에 유지합니다. 사이트에서는 정본을 직접 수정하지
않고 웹용 파생본을 `site/preview/assets/`에 만듭니다.

`main`의 `site/preview/**` 또는 배포 워크플로가 바뀌면 자동 배포합니다. GitHub Actions의
`Run workflow`로 수동 배포할 수도 있습니다.

현재 페이지는 개발 중 콘셉트 비주얼을 사용하는 공개 시안입니다. 정식 배포본으로
전환하기 전 승인된 리소스, 공유 이미지와 동영상 파일을 다시 확인합니다.

## 2026-09-08 랜딩 개선 · 로컬 검수 완료

- 먹색·황동색을 유지하고 첫 화면의 제목·장르·상태와 카드 흐름의 위계를 정리했습니다.
- 주 버튼은 `플레이 방식 보기 / See how it plays / 查看玩法`이며 카드 흐름으로 이동합니다.
- 조사대는 인물과 설명을 나눠 배치하고 역할 직접 선택 버튼을 추가했습니다. 이전·다음과 키보드 조작도 유지합니다.
- 거두는 자는 세로 원본 비율로 표시하고, 준비 중인 사건 삽화·영상 영역은 간결하게 정리했습니다.
- 이미지 10종은 기존 HTML 내장본과 바이트 해시가 같습니다. 새 그림이나 게임 규칙을 추가하지 않았습니다.
- 실제 브라우저에서 1440·390·360px × 한국어·영어·번체중국어 9조합을 검증했습니다. 가로 넘침, 제목 단어 잘림, 버튼 이동, 역할 선택·키보드 포커스, 이미지 로딩과 JS 오류 검사를 통과했습니다.
- 일반 동작과 동작 줄이기 환경에서 콘텐츠 표시를 확인했습니다. 이미지 비율과 주요 구간은 실제 화면으로 대조했습니다.
- Opus 5의 `max` 호출이 수정본 작성 후 세션 한도로 종료돼 이후 하위 작업을 Luna로 전환했습니다. Gemini의 사전 시작 검토 결과와 Luna 독립 검토를 대조하고, Luna가 역할 선택 버튼의 키보드 포커스를 마무리했습니다.
- 공개 사이트 배포와 Git push는 아직 수행하지 않았습니다. 위 결과는 로컬 수정본 검증입니다.
